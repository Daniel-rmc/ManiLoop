### 2026-09-16 · M6a · 首次跨平台 CI 修复（完成）
- 目标：修复公开仓库首次 GitHub Actions 暴露的 Windows 差异，使同一离线测试套件可跨平台运行。
- 证据：[首次运行](https://github.com/Daniel-rmc/ManiLoop/actions/runs/35046906364) 的 Linux、macOS 离线测试和 Linux OSMesa 双机器人渲染通过；Windows 出现 6 项失败、2 项错误。
- 变化：测试读取中文日志和清单时显式指定 UTF-8；为无效／超大 TOML 输入设置简短参数名称，保留原有完整输入和安全断言。
- 验证：本机 `python -m pytest -q` 为 119 项通过、7 项可选集成检查跳过、49 项子测试通过；`git diff --check` 通过。修复提交 `27092ba` 的 [GitHub Actions](https://github.com/Daniel-rmc/ManiLoop/actions/runs/35047335420) 四项检查全部通过：Windows、macOS、Linux 离线测试，以及 Linux OSMesa 的 ARX5 / Panda 渲染。
- 难点与处理：Windows 默认文本编码不能解码中文记录；pytest 将超大参数生成的测试名称写入环境变量时超过 Windows 长度限制。修复测试的跨平台假设，不改变产品行为或减少覆盖。
- 经验／决策：UTF-8 文件的读取端也应声明编码；大输入测试应提供短且可读的参数名称，避免将完整负载写入测试标识和日志。
- 后续：README 环境要求与验证文档已同步实际检查结果。可选 LIBERO Linux 工作流和 Windows 渲染仍未验证；后续功能按独立提交、CI 和工作记录维护。

### 2026-09-15 · M5b · 三类真实策略与交付验证（完成）
- 变化：正式仓库提供 `scripts/setup_vla.py`、固定模型目录、依赖清单、CLI 矩阵和网页选择器；README、VLA 安装说明、架构和第三方声明同步更新。模型、分词器和推理环境均在忽略目录，推理强制离线。
- 实测：同一 spatial task 0 / init 0 / seed 0，SmolVLA 79 步 / 2 次推理，success=true；ACT 500 步 / 5 次推理，success=false；Diffusion 108 步 / 14 次推理，success=true。模型完整权重均严格加载，三个家族均无运行错误。详见 [实验报告](../experiments/2026-09-15-libero-local.md)。
- 最终回归：正式仓库 `MANILOOP_TEST_LIBERO=1 python -m pytest -q`：126 项测试、49 项子测试通过；普通离线运行 119 项通过、7 项可选检查跳过。网页脚本语法、文档链接、Git 忽略与 `git diff --check` 通过；独立构建 wheel 成功且包含两个 worker、不含权重或运行环境。
- 交付验证：安装脚本在正式仓库重跑三个模型通过；7 项真实 LIBERO 集成检查通过，覆盖 256 像素 PNG、本体字段、重置、物理动作与任务目录。网页实际选择本地 SmolVLA 并开始执行，再次于 79 步获得官方成功判定；未发送云端 API 请求。
- 难点与处理：首次模型依赖下载耗时约 18 分钟；下载完后推理不需要网络。网页首次模型加载可能超过普通请求超时，给本地启动单独等待预算。再次开始本地任务时必须重置已完成的环境，增加对应回归。模型动作队列长度各异，因此明确区分控制步和真实神经网络推理。
- 经验／边界：DP 保留 100 次 DDPM 采样，耗时明显较长；不能为了展示速度而静默改采样设置。ACT / DP 属于非语言条件基线，SmolVLA 才是本轮语言条件 VLA。单任务成功不代表整个 LIBERO 成功率，也不代表跨任务、跨机器人或真机可用。
- 后续：扩大预先固定的任务和初始化集合，建立按策略协议分组的统计评测；按用户“先完成，再完善”的准则，本轮不增加训练框架或自动插件系统。

- 难点与处理：SmolVLA 配置残留 state6，但保存的训练统计与 LeRobot 官方 LIBERO 处理器均为 state8；保留检查点文件，使用 8 维实际状态。训练图像需双轴翻转，不能直接把网页显示图送入模型。DP 必须每个控制步更新两个历史观测，因此由 LeRobot 管理动作队列，平台逐步提交动作。
- 经验／决策：任务成功和接口可用分别记录；裁剪后的归一化 OSC 动作显式计数。完整权重严格加载，关闭重复基础模型下载；本机推理不读取云端密钥。公共检查点的标题与训练声明不能保证性能。
