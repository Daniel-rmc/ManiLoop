# 工作台布局与手动控制

工作台仍使用同一个后端、动作协议与评分器。新版入口默认显示手动控制，
不会因为切换面板而请求模型、重置场景或修改动作参数。

## 三个工作区

**手动控制**：固定轴 / TCP 自身轴、XYZ 点动、三轴旋转、夹爪、六维组合动作。
相机和按钮并排；位置误差与姿态误差直接显示。跟踪时限仅作用于手动控制。

**模型运行**：任务指令、模型连接与认证、单步 / 连续 / 暂停。
运行参数和连接诊断默认折叠，展开后仍可配置观测有效期、推理强度和预算。
点击诊断或运行才会使用模型；切换到此面板不会自动调用。

**场景设置**：选择内置任务、LIBERO、robosuite 或 RoboCasa，点击应用才会重建环境。
更换下拉选项但不应用，不会切换当前仿真。修改模型指令不等于修改官方评分规则。

分区外的“停止执行”始终可见；切到手动页不代表当前模型实验已经停止。
只有当前无任务、无动作和无在途请求时，手动动作才可提交。

## 相机与输入

“画中画 / 双相机并排”只改变展示方式，不改变图像、传感权限和物理步数。
切换分区保留当前页面的 TOML 与 Key 输入，不重建表单、不使用浏览器持久存储。
刷新页面不会自动恢复密钥；不要依赖刷新保存私人配置。

自定义六维输入可一键清零。平移以毫米、旋转以度填写，发送前统一转为 SI 单位。
界面拒绝空白、非有限数值和超限向量；服务端仍独立校验，不静默裁剪动作。
参考系与旋转的详细语义见 [手动控制说明](MANUAL_CONTROL.md)。

## 前端维护入口

- `ui/workspace.html`：新版页面结构。
- `ui/workspace.css`、`ui/workspace-layout.css`：基础主题与响应式布局。
- `ui/workspace.js`：连接、环境选择、模型运行和状态刷新。
- `ui/manual-control.js`：手动输入、单位、能力和范围检查。
- `ui/workspace-layout.js`：分区、键盘导航、相机布局及常驻停止按钮。

无需 npm、前端框架或编译步骤。Python 服务仅提供明确白名单中的本地资源，
不开放任意文件读取。构建包包含 HTML / JS / CSS，源码摘要也覆盖这些文件。

旧的 `ui/index.html` 暂作为已经运行、尚未重启的服务的兼容快照保留。
新增界面功能修改 `workspace.*`，不要继续在旧快照上叠加。
重启服务后会使用新版入口；旧进程不会因磁盘上出现新资源而自动升级。

在窄屏下，相机、控制区依次排列，状态指标分成两列。观测 JSON 和完整日志
默认折叠，展开后保留原始内容；不会把独立评分送入模型输入。

## 维护检查

```bash
python -m pytest tests/test_workspace_ui.py tests/test_manual_control.py -q
node --test tests/workspace_manual.test.mjs
```

Node 仅用于纯前端单元测试，启动工作台不需要 Node。真实仿真检查仍按各后端说明显式启用。
