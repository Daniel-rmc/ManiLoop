- [Show-Harness：VLM 机器人控制机制与 ManiLoop 工程落地分析](SHOW_HARNESS_ANALYSIS.md)：主控制链、外部 agent 边界、语义动作、数据采集、评测风险与分阶段实施方案。
- [执行反馈研究：选题讨论材料](2026-09-16-question-scoping.md)：五篇近邻预检、持续偏差／一次性失败的可证伪候选、可识别性与控制器混淆；题目与预算尚未确定。
- [GPT-6 仿真操作 Demo 改造计划](../design/GPT6_SIM_DEMO_PLAN.md)：基于当前 ManiLoop 和七个项目研读的分阶段方案，包含接口、网页、记录、验收与预算建议；方案编写时的建议保留，实施与实际测试见 M13 worknote。
- [GPT-6 首轮抓放实测](2026-09-16-gpt6-demo-first-run.md)：真实链路、一次受控尝试、失败边界及下一步问题；不是成功率评测。
- [GPT-6 完整成功 episode](2026-09-16-gpt6-success-episode.md)：46 次决策、706 官方控制步后任务成功；完整双相机录像、传感边界和官方终止范围，保留同一回合内的重试。
