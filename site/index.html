04 / START LOCALLY

把闭环运行在你的电脑上。

先启动仿真与手动控制，再接入模型。
主程序、LIBERO 仿真与 VLA 推理环境分别安装。

01

准备主环境

macOS / Linux · Python 3.12

git clone https://github.com/Daniel-rmc/ManiLoop.git
cd ManiLoop
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m maniloop demo

默认桌面演示在 127.0.0.1:8765 打开。启动与手动控制无需模型密钥。继续安装 LIBERO 时，另开终端或先按 Ctrl+C 停止演示。

完整安装与 Windows 说明 ↗
02

进入 LIBERO

自动准备独立 Python 3.10 仿真环境

.venv/bin/python -m pip install uv
.venv/bin/python scripts/setup_libero.py \
  --uv .venv/bin/uv
.venv/bin/python -m maniloop demo \
  --backend libero --port 8767

在本机打开 127.0.0.1:8767。需要 Git、网络与可用图形环境；暂不需要 VLA 权重。
