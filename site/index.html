04 / GET STARTED

Run the loop on your machine.

Start with the local workspace and manual control, then choose an optional backend and policy. Simulation runtimes and VLA inference stay isolated.

01

Set up the main environment

macOS / Linux · Python 3.12

git clone https://github.com/Daniel-rmc/ManiLoop.git
cd ManiLoop
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m maniloop demo

Open 127.0.0.1:8765 for the built-in tabletop workspace. Manual controls need no model key. Use another terminal, or stop with Ctrl+C, before installing an optional backend.

Full setup and Windows instructions↗
02

Add LIBERO

A separate Python 3.10 simulation environment

.venv/bin/python -m pip install uv
.venv/bin/python scripts/setup_libero.py \
  --uv .venv/bin/uv
.venv/bin/python -m maniloop demo \
  --backend libero --port 8767

Open 127.0.0.1:8767 on your machine. Git, network access and a supported graphics setup are required. VLA weights are optional.

CONNECT A MODEL

Give the policy a turn.

Choose GPT through a compatible image and structured-output API or official Codex login, a local LIBERO VLA preset, or Jev text primitives with a separate TypeSafe API key. Diagnose the connection before a small action.

GPT simulation guide↗API chat and diagnostics↗Local LeRobot / VLA policies↗Jev text primitives↗

Jev receives explicit instructions and public proprioception, not images. It selects a bounded primitive; local code handles units, coordinates and motion. It does not visually locate objects or provide autonomous grasping.

Model requests use the selected provider or account quota. Switching workspace panels does not trigger inference.
